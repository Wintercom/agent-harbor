# 演示流程

负责人：C，A/B 配合排查。此目录放可重复演示的说明和后续脚本，不存放用户真实项目、凭据或运行时会话数据。

## 前置条件

记录并准备已验证的 macOS/CPU、Go/Wails v2/Node 环境、实际 Agent CLI、一个模型账号、一个只读远程认证 MCP 和独立非敏感工作区。当前应用及演示脚本尚未实现，没有可执行的启动命令。

## 演示顺序

1. 桌面宿主机表单连接模型与 MCP；连接后输入框清空，展示脱敏状态。
2. 选择专用演示目录，说明 direct 会修改原文件，输入含一次 MCP 查询和文件写入的小任务。
3. 启动真实 Agent，展示任务输出、工具调用和隔离边界。
4. 用 [security](../security/README.md) 的受限检查展示越界文件、非 Gate 网络被拒绝。
5. 停止任务，展示无残留进程、会话令牌撤销，再运行第二轮。

## 后续产物与验收

实现可用后再增加 `run.sh` 等真实脚本及确切命令；脚本只读取或提示用户录入宿主机凭据，不包含默认 Key。录屏与真实运行结果分别说明，测试 fixture 明确标为模拟上游。失败时展示错误和已有证据，不以假输出冒充成功。

排期和缩减顺序以[两天方案](../docs/MVP-2D3P.md)为准。
