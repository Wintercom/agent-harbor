# 页面视图

负责人：产品 C。建议先实现两个原生 JavaScript 页面，文件尚未创建。

| 文件 | 内容与验收 |
|---|---|
| setup.js | 模型/MCP 连接、工作区选择、任务输入与启动；空输入或连接未就绪时禁用启动 |
| session.js | 真实状态、文本输出、脱敏活动、错误和停止；停止后允许再次提交新会话 |

输入凭据只在配置视图出现，提交完成清空；任务输出和 MCP 返回按不可信文本展示。两天版 direct 模式明确提示修改原文件，账号只在 Go 内存保留、重启需重新输入。

不自行发送 Gate 请求，不模拟隔离成功，不另建会话状态机。方法通过上级 api.js 调用，展示以 Go 事件为准。
