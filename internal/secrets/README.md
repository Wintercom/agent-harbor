# 宿主机凭据

负责人：B。两天版只使用 Go 应用进程内存，不持久化到文件、数据库、浏览器存储或钥匙串；重启后需要重新连接。

## 建议文件（尚未实现）

`store.go` 负责保存、引用、删除和生命周期管理。模型与 MCP 采用独立账号引用，SecretStore.Resolve 能力只注入 Gate，不提供给 Kit、Runtime 或前端。

## 数据边界

UI 经受限 Wails 绑定单向提交凭据；返回只含引用、显示名称、脱敏地址与连接状态。连接测试由 Gate 使用对应凭据完成；连接失败不返回原始认证请求，不留下错误可用状态。

提交完成清空 UI 字段，不在事件、日志、异常堆栈附加输入对象；不经命令行参数或完整环境传给子进程。执行面里的 Sentinel 不是本存储保存的上游凭据。

停止会话撤销该会话能力，不必删除仍由用户连接的账号；断开账号或应用退出时释放相应凭据引用。Go 内存释放不保证物理字节立即归零，不能宣称实现了内存安全擦除。

## 验收

验证引用隔离、删除后解析失败、连接错误脱敏，以及 Agent env/配置和 UI 返回事件中均无真实 Key。测试只使用专门的可轮换凭据，不把测试 Key 提交到本目录。

精确 Put/Resolve/Delete 与 AccountCatalog.Lookup 语义见 [CONTRACT.md](../../docs/CONTRACT.md)：A 只获得 Lookup 窄接口，不能经目录接口读取真实凭据。连接成功才 Put，失败不留候选账号。并行调用边界见 [MODULE-DESIGN.md](../../docs/MODULE-DESIGN.md)。
